# CRUD Product Management App

A simple CRUD web application built using Flask, MySQL, PyMySQL, HTML, Jinja, and CSS.

## Features

- Create products
- View products
- Update products
- Delete products
- Success and error flash messages
- Simple and clean UI

## Technologies Used

- Python
- Flask
- MySQL
- PyMySQL
- HTML
- Jinja
- CSS
